# HMI 屏端对照表（26gongxun 版）

MCU 端代码已就绪：`BSP/hmi_tjc.c`（驱动）+ `APP/hmi_menu.c`（菜单逻辑）。
本文档是屏端改造清单——在陶晶驰 HMI 编辑器里打开 `menu_hmi.HMI` 照着对。
屏端只需要保证**页面创建顺序**和**页内控件创建顺序**（ID 自动对齐），不用写任何脚本。

---

## 0. 接线与串口设置

| 项 | 值 |
|---|---|
| MCU 串口 | USART2：PA2(TX)→屏 RX，PA3(RX)←屏 TX，共 GND |
| 波特率 | **9600**（MCU 端 board.c 已定；屏端工程设置里也改 9600） |
| 屏端 bkcmd | 建议 1（减少错误码噪声） |
| 编码 | 屏端默认 GBK；MCU 动态中文已按 GBK 字节发送，**屏端字体必须含中文** |

> 嫌 9600 刷新慢：屏端改 115200 + `BSP/board.c` 里 USART2 波特率同步改，代码无需其它改动。

## 1. 页面规划（创建顺序即页 ID）

| 页 ID | 页名 | 功能 | MCU 枚举 |
|---|---|---|---|
| 0 | 主菜单 | 进入各功能页 | HMI_PAGE_MAIN |
| 1 | 任务显示 | 任务码 + 两批明细（接 task_code） | HMI_PAGE_TASK |
| 2 | 扫码调试 | 触发扫码/显示结果/统计 | HMI_PAGE_SCAN |
| 3 | 底盘遥控 | 方向键按住走、松开停 | HMI_PAGE_REMOTE |

你现在的 `menu_hmi.HMI` 里已有 0~12 页，两种对齐方式：
1. **推荐**：把这 4 页挪到最前（0~3），旧页顺延；
2. 或者保持旧页不动，改 `APP/hmi_menu.h` 里的 `HMI_Page_t` 枚举值对上实际页号。

## 2. 逐页控件清单（页内创建顺序 = 控件 ID）

### page0 主菜单
| 创建序 | objname | 类型 | 文本 | 说明 |
|---|---|---|---|---|
| 0 | t0 | 文本 | 26 搬运机器人 | 标题 |
| 1 | b0 | 按钮 | 任务 | 进 page1 |
| 2 | b1 | 按钮 | 扫码 | 进 page2 |
| 3 | b2 | 按钮 | 遥控 | 进 page3 |

### page1 任务显示（MCU 每 200ms 自动刷新）
| 创建序 | objname | 类型 | 内容 |
|---|---|---|---|
| 0 | t0 | 文本 | 原始任务码，如 `156+123+516+231`；无任务显示 `NO TASK` |
| 1 | t1 | 文本 | 第一批明细：`B1 红>环1 黑>环2 浅蓝>环3` |
| 2 | t2 | 文本 | 第二批明细：`B2 黑>环2 红>环3 浅蓝>环1` |
| 3 | b0 | 按钮 | 重新扫码（发触发命令给 GM65） |
| 4 | b1 | 按钮 | 返回 page0 |

> t1/t2 是 GBK 字节写入，屏端 t1/t2 使用的字体要含中文（红黄蓝绿黑浅蓝、环）。
> 任务数据要等恢复扫码任务后才有；调试模式下本页显示 NO TASK 属正常。

### page2 扫码调试
| 创建序 | objname | 类型 | 内容 |
|---|---|---|---|
| 0 | t0 | 文本 | 最近一条原始码 |
| 1 | t1 | 文本 | 结果：`OK` / `无效`（GBK） / `--` |
| 2 | t2 | 文本 | 统计：`S=条码行 OK=入库 BAD=拒绝` |
| 3 | b0 | 按钮 | 触发扫码 |
| 4 | b1 | 按钮 | 返回 page0 |

### page3 底盘遥控（纯事件驱动，无周期刷新）
| 创建序 | objname | 类型 | 文本 | 按下 | 松开 |
|---|---|---|---|---|---|
| 0 | b0 | 按钮 | 前 | 'W' 前进 | 急停 |
| 1 | b1 | 按钮 | 后 | 'S' 后退 | 急停 |
| 2 | b2 | 按钮 | 左 | 'A' 左移 | 急停 |
| 3 | b3 | 按钮 | 右 | 'D' 右移 | 急停 |
| 4 | b4 | 按钮 | 停 | 急停 | 急停 |
| 5 | b5 | 按钮 | 返回 | 急停 + 回 page0 | — |

方向命令走 `Chassis_Remote_Command('W'/'S'/'A'/'D')`，与 USART1 的 WASD 遥控并存、逻辑同源。
速度档调节（`Chassis_Remote_SpeedAdjust`）暂未绑屏，需要时在 page3 加 b6/b7 并告知 MCU 侧。

## 3. 自检流程

1. 屏端编译下载 → 上电应停在 page0 并显示标题（MCU 上电会发 `HMI_Menu_Init` 跳主菜单）。
2. 点"遥控"进 page3 → 按住"前"车应前进，松开即停（配合 USART1 调试回显 `[REMOTE] cmd=w`）。
3. 接好 GM65 后进 page2 → 点"触发扫码"，t0 应出现条码内容。
4. 某控件无反应：先查屏端该页创建顺序是否与本表一致（ID = 页内创建序）。

## 4. MCU 端数据流备忘

```
GM65 → Scanner_Process → Scanner_GetCode → TaskCode_Accept（解析入库）
                                          └→ HMI_Menu_NotifyCode（屏上显示结果）
task_code 单例 ← TaskCode_Current() ← hmi_menu 周期刷新任务页
```
